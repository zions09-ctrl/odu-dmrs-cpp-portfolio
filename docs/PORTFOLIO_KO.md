# 5G NR O-DU 실시간 DM-RS 제어 시스템 | C++ 포트폴리오

## 프로젝트 요약

**목적:** 5G NR의 PDSCH DM-RS 심볼 밀도를 채널 상황에 따라 변경하는 제어 경로를 설계하고, 실제 스케줄러 안에서 결정·적용·검증이 이뤄지는지 확인한다.

**배경:** DM-RS 밀도를 줄이면 데이터에 사용할 자원이 늘어나지만, 빠르게 변화하는 채널에서 채널 추정 성능이 악화될 수 있다. 반대로 밀도를 높이면 추정용 신호 자원이 늘지만 데이터 자원이 줄어든다.

**핵심 구현 개념:** 슬롯 단위 입력 CQI → 정책 선택 → DM-RS mask 조회 → 기존 자원과 비교 → no-op 또는 변경 제안 → 3계층 일관성 검증.

**원래 연구 보고 결과:** OCUDU v26.10.0 / software RU / TDD, SCS 30 kHz, 명목 슬롯 500μs. 9개 Retained Run의 352,054 trace 행, V1/V2 위반 0개(원 보고), 로컬 dApp Hook p50 0.273~0.524μs, p99 최대 1.349μs. 관측 최대값은 3.096ms로, hard real-time 보장과 다르다.

**현재 제공되는 코드:** 위 원 연구 내용을 토대로 **이번 세션에서 새로 작성한 C++20 독립 실행형 재구성 코드**. 소스/테스트/벤치마크가 실제로 빌드되며, 예제 입력은 합성 CQI이다. 원래 OCUDU 수정본 전체를 확보했다는 뜻이 아니다.

## 코드에서 설명 가능한 역량

- C++20의 데이터 구조, `noexcept` 함수, atomic snapshot을 사용한 슬롯 경로 설계
- 입력/지원 범위 검증과 상태값 기반 fail-closed 처리
- 무변경 상태(255)를 실패와 구분하는 idempotent actuation 설계
- Popcount에 기반한 자원 사용량 불변식 테스트
- CQI 임계치 6/13 경계값 테스트, invalid input 및 동시성 테스트
- 계측 범위를 정확하게 표기한 독립 마이크로벤치마크
